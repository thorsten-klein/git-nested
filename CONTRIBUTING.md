# Contributing to git-nested

Thank you for helping!

- [Development](doc/contributing/development.md): setup, tests, checks and
  commit messages.
- [Documentation](doc/contributing/documentation.md): how to write and build
  the docs.
- [Architecture](doc/architecture/index.md): how the code is built.

The short version:

```bash
uv sync          # install everything
uv run poe all   # every check CI runs
```

For security problems, see [SECURITY.md](SECURITY.md). Do not open a public
issue.
