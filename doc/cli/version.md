# `git nested version`

Print version information.

```text
git nested version
git nested --version
```

## What it does

`version` prints:

- the git-nested version,
- the copyright and the project URL,
- where git-nested is installed,
- the git version.

```text
git-nested Version: 1.1.1
Copyright 2026 Thorsten Klein <thorsten.klein.git@gmail.com>
https://github.com/thorsten-klein/git-nested
/usr/lib/python3/site-packages/git_nested/commands/version.py
Git Version: 2.43.0
```

It works outside a repository too.

Please add this output to every bug report.
